الحاج الزوبير - نسخة جاهزة للربط مع Firebase

المشروع: elhaj-zoubir

هذه النسخة تحفظ البيانات محلياً وتزامنها مع Cloud Firestore في مشروع Firebase نفسه.
عند فتح التطبيق على هاتف آخر، وبعد الاتصال بالإنترنت، يتم جلب البيانات من Firebase.

الملفات المهمة:
- index.html: التطبيق واتصال Firebase
- firebase.json: إعدادات Firebase Hosting/Firestore
- firestore.rules: قواعد Firestore الحالية

ملاحظة أمنية:
هذه النسخة لا تستخدم كلمة مرور، ولذلك قواعد Firestore الحالية تسمح بالقراءة والكتابة.
لا تجعل المستودع أو الرابط عاماً مع هذه القواعد إذا كانت البيانات حساسة.
