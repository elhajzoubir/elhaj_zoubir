# الحاج الزوبير — النسخة الأصلية + مزامنة Firebase

هذه النسخة مبنية على النسخة الأصلية التي كانت تعمل بشكل طبيعي، مع إضافة مزامنة Firebase فقط.

## ما تم الحفاظ عليه
- الفاتورة الأصلية.
- الطباعة وحفظ PDF.
- حساب الفلاح والحسابات اليومية والشهرية.
- دخول الصندوق والديون.
- Bon d’achat وطباعة الوصل.
- جميع الشعارات والملفات الأصلية.

## المزامنة
- Firebase Authentication عبر Anonymous.
- Firestore لمزامنة الفواتير والديون ودخول الصندوق وBon d’achat.
- المزامنة تلقائية عند فتح التطبيق وعند الحفظ.
- يوجد زر «مزامنة الآن» للاختبار اليدوي.
- إذا انقطع الإنترنت، يبقى التطبيق يعمل محلياً ثم يعيد المحاولة عند الاتصال.

## إعداد Firebase
مشروع Firebase المستخدم هو: `elhaj-zoubir`.
يجب أن يكون Anonymous Authentication مفعلاً.

### قواعد Firestore
القواعد المقترحة موجودة في `firestore.rules`.
إذا كنت تعدل القواعد من Firebase Console، انسخ محتوى هذا الملف إلى Firestore > Rules ثم اضغط Publish.

> ملاحظة: هذه القواعد تسمح للمستخدمين المجهولين بالقراءة والكتابة، لذلك لا تستخدم هذا الإعداد لتطبيق يحتوي بيانات حساسة أو خاصة جداً.

## GitHub Pages
ارفع ملفات المشروع إلى جذر المستودع، وتأكد أن `index.html` موجود في الجذر.
