# الحاج الزوبير — الفاتورة مع المزامنة

هذه النسخة مبنية على نسخة **بدون مزامنة** التي أرسلتها، وتمت إضافة Firebase للمزامنة فقط.

## ما تم الحفاظ عليه
- أزرار الطباعة الأصلية.
- زر حفظ PDF الأصلي.
- تصميم الفاتورة وBon d’achat.
- الحسابات ودخول الصندوق والحساب الشهري.

## ما تمت إضافته
- مزامنة الفواتير.
- مزامنة الحسابات/الديون ودخول الصندوق.
- مزامنة ملاحظات حساب صافي الشهر.
- مزامنة Bon d’achat.
- خانة رمز مزامنة من الإعدادات.
- مزامنة تلقائية عند الحفظ، وفحص دوري.

## إعداد Firebase
تم وضع إعدادات Web App التي أرسلتها داخل `firebase-config.js`.

يجب أن يكون **Anonymous / Anonyme** مفعلاً، وهو ظاهر عندك أنه مفعّل بالفعل.

يجب كذلك إنشاء/تفعيل **Cloud Firestore Database** ثم وضع هذه القواعد:

```text
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /hz_sync/{roomId} {
      allow read, write: if request.auth != null;
    }
  }
}
```

## استعمال المزامنة
1. ارفع كل الملفات إلى جذر `main` في GitHub Pages.
2. افتح التطبيق.
3. ادخل إلى **الإعدادات**.
4. اكتب رمزًا مثل `ZOUBIR2026`.
5. اضغط **حفظ الرمز ومزامنة الآن**.
6. في الجهاز الثاني اكتب **نفس الرمز تمامًا**.

> لا تستخدم رمزًا سهل التخمين إذا كان التطبيق منشورًا للعامة.
