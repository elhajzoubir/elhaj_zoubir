- اللوغو في اليسار بشكل احترافي وبدون رقم الهاتف.
- معلومات الفاتورة في اليمين.
- إجمالي البيع والملخص في اللوحة اليسرى كما في التصميم المطلوب.
- اللوحة اليمنى فارغة بدون خانة ملاحظات.

- تمت إضافة حساب الفلاح: قائمة الفلاحين، تجميع جميع الفواتير لكل فلاح، المبلغ الكلي، بعد نزع العمولة، المصروف، والصافي.
- تمت إضافة زر طباعة حساب الفلاح مع تفاصيل جميع الفواتير.
